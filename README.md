# 🚗 AI-Based Road Accident Risk Prediction

## 📌 Project Overview

This project uses Machine Learning to predict road accident risk levels based on road, traffic, weather, and environmental conditions.

The system classifies accident risk into:

- 🟢 Low
- 🟡 Medium
- 🔴 High

It also provides accident statistics and hotspot analysis using accident location data.

## 🤖 Machine Learning

Three classification models were tested:

- Random Forest
- Decision Tree
- Logistic Regression

Random Forest achieved the best accuracy of **94.37%** and was selected as the final model.
