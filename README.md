# Accident Risk Prediction Using Machine Learning

## Project Overview
This project predicts road accident risk levels (High, Medium, and Low) using machine learning techniques based on road and environmental conditions.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest Classifier
- Streamlit

## Machine Learning Model
A Random Forest Classifier was trained to predict accident risk levels.

**Model Accuracy: 94.37%**

## Project Features
- Data preprocessing
- Machine learning model training
- Accident risk prediction
- Interactive Streamlit web application
- Model evaluation

## Project Structure
- `data/` – Dataset files
- `models/` – Trained machine learning model
- `src/` – Python source code
- `requirements.txt` – Required Python libraries

## How to Run

1. Clone this repository:
   `git clone https://github.com/RIshi282801/accident-risk-prediction.git`

2. Install the required libraries:
   `pip install -r requirements.txt`

3. Run the application:
   `streamlit run src/app.py`

## Project Purpose
Developed as an academic project to explore machine learning applications in road safety and accident risk prediction.
